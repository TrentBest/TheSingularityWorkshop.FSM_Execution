03 / CODE RED evidence handoff

A notice is not the evidence.

CiAi sends a metadata-only artifact-ready notice. Execution correlates that notice to its own persisted request, retrieves immutable bytes, verifies integrity, and validates the authoritative evidence packet before using it in the task lifecycle.

1 · Noticemetadata only
2 · Receiptdurable + idempotent
3 · Retrieveimmutable artifact
4 · Verifysize + SHA-256
5 · Validateworkflow-evidence.v2
6 · Correlatetask + exact SHA
Diagnostic context

ciai.test-results.v1 can help a bounded HeadlessAi analysis understand test failures. It is not the authoritative workflow evidence packet and is not a release verdict.

Authoritative candidate evidence

ciai.workflow-evidence.v2 carries the exact workflow/run/attempt/candidate provenance. Acceptance or retrieval receipts do not authorize repository mutation, merge, release, or publication.

04 / Trust and authority

Evidence, execution, and permission are different things.

Execution can report what happened.

Accepted, Running, Succeeded, Failed, Cancelled, and TimedOut are distinct lifecycle outcomes. A handler that ignores cancellation cannot be forcibly stopped by a cooperative token.

Execution does not infer permission.

Model output, a green CI run, a valid evidence packet, or a CODE RED incident does not grant a repository capability. Human authorization remains in the host adapter.

This is an architectural workbench, not a live operations console. Every scenario is synthetic and runs entirely in this page.
